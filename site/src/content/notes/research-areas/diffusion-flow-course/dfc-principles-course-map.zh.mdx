# 一張地圖讀完整門課

> Diffusion & Flow Models 課程 W2（技術第 1 講），第 5 篇。這篇放在 W2 最後：不是用名詞預告名詞，而是把前四篇真的算過的物件放回一張可以拿去讀論文、選專題與設計實驗的地圖。

一篇新論文可能同時出現 DDPM、score、ODE、guidance、distillation 和一個新 metric。每個字都似曾相識，卻很難回答它到底改了什麼。這時最沒效率的做法，是從標題猜它屬於哪個「模型家族」；更穩的做法，是把方法拆開，找出它在哪個技術位置做選擇。

W2 前四篇已經替這張地圖準備了四個支點：

- [生成就是把分布搬過去](/personal_website/zh/notes/dfc-principles-transport-map) 分清 finite samples、unknown $p_{\mathrm{data}}$、particle 與 distribution；
- [Corrupt Then Reverse](/personal_website/zh/notes/dfc-principles-corrupt-and-reverse) 用 Gaussian Markov chain 建出一條 data-to-noise path；
- [同一個 Noisy Point，可以學哪一種訊號？](/personal_website/zh/notes/dfc-principles-prediction-targets) 分開 clean data、noise、score、velocity 與 sampler；
- [Flow Matching：直接學每個位置該往哪裡走](/personal_website/zh/notes/dfc-principles-flow-matching) 從 conditional path 造出 velocity target，再用 ODE 生成。

現在把它們疊成同一個流程：

```text
有限 data samples + 可取樣的 base
                ↓
        probability path
                ↓
   可計算的 conditional training target
                ↓
      neural network 學局部物件
                ↓
        SDE / ODE / flow map
                ↓
       numerical sampling
                ↓
  generated samples + task-specific evidence
```

這不是說所有方法都一樣。它說的是：**先看每一格放了什麼，再判斷論文真正改了哪一格，以及那個改動如何傳到下游。**

## 先用五格版本找到方向

下面的互動圖保留最粗的五層：path、target、sampler、guidance、evaluation。切換讀圖角度，看每個研究問題先點亮哪一層；接著再用下一節的十格版本做精確定位。

粗圖的用途是避免迷路，不是替代數學。真正讀方法時，我們把五格展開成十個位置。

## 十個位置，十個後續問題

| 位置 | 代表寫法 | 讀論文時先問 |
|---|---|---|
| 1. Data、state space、base | $X_1\sim p_{\mathrm{data}}$，$X_0\sim p_{\mathrm{base}}$ | 合法 sample 長什麼樣？為何這個 base 容易抽？ |
| 2. Probability path | $(p_t)_{t\in[0,1]}$ 或 $X_t=I_t(X_0,X_1,Z)$ | 中間 distributions 怎麼定？endpoints 與 time convention 是什麼？ |
| 3. Conditional construction / target | $A_t=A_t(X_0,X_1,Z)$ | 哪些 latent variables 只在訓練時知道？target 為何可計算？ |
| 4. Learned object / objective | $\min_\theta\mathbb E[w(t)\|F_\theta(X_t,t,c)-A_t\|^2]$ | 網路實際輸出 noise、score、denoiser 還是 velocity？ |
| 5. Dynamics | $dX_t=b_t(X_t)dt+g_t\,dW_t$ 或 $\dot X_t=v_t(X_t)$ | 哪個 dynamics 真的具有想要的 marginals？ |
| 6. Numerical sampler | $x_{k+1}=x_k+h\hat v_\theta(x_k,t_k)$ | 有限步如何近似 dynamics？NFE、error、stability 怎麼取捨？ |
| 7. Guidance / conditioning | $\nabla_x\log p_t(x\mid c)=\nabla_x\log p_t(x)+\nabla_x\log p_t(c\mid x)$ | 條件資訊在哪裡改變局部方向？quality–coverage trade-off 是什麼？ |
| 8. Fast generation / flow map | $G_\theta(x_s,s,t)\approx\Phi_{s\to t}(x_s)$ | 能否學跨時間的大步，而非每次只走 infinitesimal step？ |
| 9. Structured state / application constraints | $q_t(x'\mid x)$ on $\mathcal X$ | Gaussian corruption 是否合法？representation、transition、constraint 要改什麼？ |
| 10. Evaluation / evidence | $\widehat{\mathbb E}[g(X)]=\frac1m\sum_{j=1}^m g(\tilde x^{(j)})$ | 哪組 evidence 同時檢查 quality、coverage、constraint、cost 與 failure modes？ |

一張表看完不等於學完；它只是讓後面的推導各有座標。以下把十格之間最重要的依賴補起來。

## 前四格決定「模型要學哪一道題」

第一格先決定問題本身。圖片常被表示成 continuous-valued tensor，token 是 discrete state，分子或物理場可能還有 symmetry、conservation 或 feasibility constraints。$p_{\mathrm{base}}=\mathcal N(0,I)$ 很常見，但不是生成模型定義的一部分；重點是能夠可靠 sampling，並有一條可處理的路連到資料。

第二格的 probability path 不只畫兩個 endpoints。以 diffusion forward clock 為例，

$$
Y_\tau=\alpha_\tau X+\sigma_\tau\epsilon
$$

同時決定每個 noise level 的 marginal distribution 與 SNR。以直線 Flow Matching 為例，

$$
X_t=(1-t)X_0+tX_1
$$

則 coupling 也參與決定中間的 conditional paths。即使 endpoints 相同，改 schedule、interpolation 或 coupling，training examples 仍會改變。

第三格問的是「老師怎麼出有答案的題目」。diffusion 訓練時知道自己抽的 $X,\epsilon,\tau$；Flow Matching 訓練時知道抽到的 $X_0,X_1,t$。這些 latent variables 在生成時不會提供給模型，卻能製造 conditional target $A_t$。

第四格才是 neural network 接到的 objective：

$$
\mathcal L(\theta)
=
\mathbb E\left[
w(t)\left\|F_\theta(X_t,t,c)-A_t\right\|^2
\right].
$$

固定 $(X_t,t,c)$ 後，L2 optimum 是

$$
F^*(x,t,c)
=
\mathbb E[A_t\mid X_t=x,t,c].
$$

這一行是 denoising 與 conditional Flow Matching 共用的 regression backbone。但不要因此說它們完全相同：$p_t$、$A_t$、weight $w(t)$、time sampling 和下游 dynamics 都可能不同。

讀論文時若只看到「我們改成預測 $v$」就停下來，會漏掉前三格；而前三格常常正是 training difficulty 與 inductive bias 的來源。

## 第五、六格決定「學到之後怎麼走」

learned object 必須被放進 dynamics 才能產生一條 sample path。Flow Matching 直接提供 ODE velocity：

$$
\frac{dX_t}{dt}=v_\theta(X_t,t).
$$

score-based diffusion 可以使用 reverse-time SDE。若這一小段暫時採用 diffusion 的 data-to-noise forward clock $\tau$，並把 forward SDE 寫成 $dY_\tau=f_\tau(Y_\tau)d\tau+g_\tau dW_\tau$，那麼在適當 regularity conditions 下，與它共享同一族 forward marginals 的 probability-flow ODE 是

$$
\frac{dY_\tau}{d\tau}
=
f_\tau(Y_\tau)-\frac12g_\tau^2\nabla_y\log p_\tau(Y_\tau).
$$

生成時從 noise 端把 $\tau$ 由大積到小。本課其他 flow 圖使用相反的 generation clock $t=1-\tau$；看到正負號以前，先確認作者的 time convention。

「共享 marginals」不表示 individual trajectories 相同。SDE 沿路有 Brownian noise，ODE 在給定初始 seed 後是 deterministic；它們可以在每個時刻產生相同 distribution，particle path 卻完全不同。W4 會從 Fokker–Planck equation 把這件事推清楚。

即使 continuous dynamics 完全正確，電腦仍要選 finite steps。Euler 只用目前 slope：

$$
x_{k+1}=x_k+h\,\hat v_\theta(x_k,t_k).
$$

較高階 solver 會多看幾次 field，以減少 local truncation error。這裡至少有兩種誤差：field prediction error 與 discretization error。增加 sampling steps 主要處理後者，未必修得好前者；換更大 network 主要處理前者，也不保證粗步長穩定。後面比較 sampler 時，會固定其中一項再看另一項。

## 第七、八格改變目的地與步數

conditional generation 多一個條件 $c$：文字、label、觀測、幾何限制或其他 context。Bayes identity 給出 classifier guidance 的基本方向：

$$
\nabla_x\log p_t(x\mid c)
=
\nabla_x\log p_t(x)
+
\nabla_x\log p_t(c\mid x).
$$

它告訴我們 conditioning 不是生成結束後才替 samples 排名；條件可以在每個 noisy state 改變局部 score。classifier-free guidance 則用 conditional 與 unconditional model outputs 的組合，避免額外 classifier。guidance scale 提高時可能改變 fidelity 與 diversity 的平衡，因此「更聽 prompt」不能單獨代表 distribution 更好。

另一條研究線問：為什麼一定要查詢 field 許多次？若 exact ODE flow map 記作 $\Phi_{s\to t}$，它把時間 $s$ 的狀態直接送到時間 $t$，並滿足 composition：

$$
\Phi_{s\to t}
=
\Phi_{u\to t}\circ\Phi_{s\to u},
\qquad s<u<t.
$$

fast generation 希望學一個近似的大步 map

$$
G_\theta(x_s,s,t)
\approx
\Phi_{s\to t}(x_s),
$$

或讓同一 trajectory 上不同時間的預測保持 consistency。這改的不是單純把 Euler 的 $h$ 調大；模型學習的 object、teacher information、consistency constraint 與 error accumulation 都可能一起改變。後面的 fast-generation 單元會把 solver acceleration、distillation、consistency 與 flow-map learning 分開定位。

## 第九、十格問「換資料後還成立嗎」

continuous image model 常把 Gaussian noise 直接加到 real-valued coordinates；但 token、graph edge、molecule type 或其他 structured state 不一定允許這個 operation。若 state space 是 finite set $\mathcal X$，forward corruption 可以改由 transition kernel 或 matrix 描述：

$$
q_k(x_k\mid x_{k-1}),
\qquad x_k\in\mathcal X.
$$

Austin 等人的 D3PM 展示了 discrete state space 中可設計不同 transition matrices，包括 uniform、鄰近關係與 absorbing-state 類型。重點不是把 continuous 公式換一個字母，而是重新回答：哪些中間 state 合法、怎麼移動、reverse target 是什麼、sampling cost 如何計算。

真實 application 還會把 constraint 放回地圖。image、molecule、PDE field 與 trajectory 可以共享 path／target／sampler 的抽象問題，但它們不共享同一個「有效 sample」定義。representation 可能需要保留 symmetry；sampling 可能必須符合 boundary 或 feasibility；evaluation 可能更在意 rare failure，而不是平均視覺品質。

最後一格因此沒有一個萬用 scalar。抽 $m$ 個 generated samples $\tilde x^{(j)}$ 後，任何 empirical metric 都只檢查某個 test function $g$：

$$
\widehat{\mathbb E}_{p_\theta}[g(X)]
=
\frac1m\sum_{j=1}^m g(\tilde x^{(j)}).
$$

若 $g$ 只量清晰度，它看不見 mode coverage；若只量 constraint violation rate，它不會告訴你 samples 是否有用；若只報最好看的例子，它甚至不估計 expectation。研究設計要把 quality、coverage、constraint、compute、stability 和 task-specific failure evidence 組起來，並明說每一項仍看不見什麼。

## 用地圖讀三種典型方法

把十格壓回三列，可以看出名稱之外的差異：

| 方法視角 | Path / conditional target | Learned object | Dynamics / sampler |
|---|---|---|---|
| DDPM / denoising | Gaussian Markov corruption；已知 $x_0,\epsilon,k$ | reverse mean 的 parameterization，常以 $\epsilon$ 或 $x_0$ regression | discrete reverse kernels |
| Score-based SDE | forward SDE 的 marginals；perturbation kernel | $s_\theta(x,t)\approx\nabla_x\log p_t(x)$ | reverse SDE 或 probability-flow ODE + solver |
| Flow Matching | chosen conditional paths；conditional velocity | marginal velocity $v_\theta(x,t)$ | ODE + solver |

這張表不把三者硬說成同一個演算法。它只指出它們共享「設計 path → 造 conditional supervision → 學 local object → 數值生成」的骨架。Lai 等人的 *The Principles of Diffusion Models* 以 variational、score-based 與 flow-based 三個觀點整理 diffusion 的共同原理；W3–W5 會沿這三個入口，各自推到能檢查的式子，再在 dynamics 層統一。

## 從地圖長出一個 project seed

W2 的最後一步不是選一篇最熱門的 paper，而是挑一個**可改動的位置**，並把它接回一個可觀察的問題。可以從下面七格選一個主要位置：

`path`　`prediction target`　`sampler`　`guidance / conditioning`　`representation`　`evaluation`　`application constraint`

每個 seed 先填四句：

> 我想研究＿＿＿＿情境中的＿＿＿＿現象或限制。
>
> 它主要落在地圖的＿＿＿＿位置，並可能影響下游的＿＿＿＿。
>
> 最小可重現的 toy、baseline 或 analytic case 是＿＿＿＿。
>
> 如果觀察到＿＿＿＿證據，我會放棄或修改原本的判斷。

同一個人先寫兩個 seeds，不急著承諾。只有「用 diffusion 做醫療／分子／圖」還不是研究問題；只有「換一個 sampler」也還不是 mechanism。地圖要逼我們多說一步：**哪個 object 改了、為什麼可能改善哪個 failure、用什麼 evidence 能推翻這個解釋。**

W3 會從這張低解析度地圖進入第一條完整數學線：Gaussian corruption 的 conditional 與 marginal、L2 denoiser 的 optimum、score，以及 denoising–score bridge。想在課前先用較慢的節奏暖身，可以依序讀 [Denoising：生成可以被看成局部修復](/personal_website/zh/notes/n2d-denoising) 與 [Score Function：資料分布的局部方向感](/personal_website/zh/notes/n2d-score-function)。
