# 霧中下山，一步該走多大：梯度下降的一頁

<Objectives>
- 從 Taylor 一階項說出「為什麼往負梯度走」，並說出這個理由只在多小的範圍內有效。
- 寫出二次目標下的更新規則，導出穩定條件 $\eta<2/\lambda_{\max}$，並說出收斂**速度**由條件數而非 $\lambda_{\max}$ 決定。
- 在共用 toy 上量出跨過門檻的後果，並示範「換一個特徵單位」如何把可用的學習率縮小二十個數量級——以及標準化怎麼把它換回來。
</Objectives>

<Prereq items={frontmatter.prereqs} />

## 起點：霧裡下山

<Ref to="math-gradient" mode="title"/> 那一篇的情境：你在山上，濃霧，能見度一公尺。你只能量出腳下地面往哪個方向最陡。你想下到谷底。

策略很自然：**往最陡的下坡方向走一步，停下來，重新量，再走一步。**

真正的問題不是方向，是**一步走多大**。

- 走 10 公分：方向幾乎不會過期，但要走一整天。
- 走 50 公尺：省時間，但這 50 公尺裡地形早就變了——你可能衝過谷底，衝上對面的山坡。
- 走 500 公尺：你會在兩側山壁之間來回彈跳，每次都比上次更高。

第三種情況值得注意：**它不是「慢一點」，是往反方向去。** 而且一旦開始，會越來越快。

這一篇把這件事變成一個可以先算出來的數字：對一個給定的問題，存在一個門檻 $\eta^\star$，低於它收斂、高於它發散，中間沒有灰色地帶。實測會看到門檻兩側是 $0.0415$ 與 $6.6\times10^{122}$。

<Ask>
往負梯度走一步——這一步該走多大？<br />
走太大只是慢一點，<br />
還是會往反方向去？
</Ask>

<Question id="Q1">
把「往最陡的下坡走一步」翻成數學：更新規則怎麼寫？「這個方向會讓損失下降」這個保證從哪裡來、只在什麼範圍內成立？「步伐太大」在式子裡是哪個量太大？

<Answer>
**更新規則。** 參數 $\theta\in\mathbb R^p$，目標 $L(\theta)=\widehat R_n(f_\theta)$，

$$
\theta_{k+1}=\theta_k-\eta\,\nabla L(\theta_k).
$$

**下降的保證來自 Taylor。** 在 $\theta_k$ 附近展開（<Ref to="math-taylor" mode="title"/>）：

$$
L(\theta_k+\Delta)=L(\theta_k)+\nabla L(\theta_k)^\top\Delta+O(\lVert\Delta\rVert^2).
$$

取 $\Delta=-\eta\nabla L$，一階項是 $-\eta\lVert\nabla L\rVert^2\le0$——**保證下降**。但這是**一階**的保證：它只在二階項還小的時候有效。$\eta$ 一大，$O(\lVert\Delta\rVert^2)$ 那一項就翻身，把一階的下降吃掉還有剩。

**「太大」是哪個量。** 二階項的係數是 Hessian $\nabla^2L$。所以「安全的步伐」不是絕對的長度，而是**相對於曲率**的長度：曲率大的方向（山壁陡峭）能走的步伐小，曲率小的方向（谷底平緩）能走的步伐大。麻煩在於**只有一個 $\eta$ 要同時服務所有方向**——最陡的那個方向決定你的上限，最平的那個方向決定你要走多久。這兩個數的比值就是條件數，它是這一篇真正的主角。
</Answer>
</Question>

## 山谷的形狀決定一切

把損失曲面想成一個橢圓形的碗。碗在某些方向很陡（截面窄），某些方向很平（截面長）。

- $\eta$ 由**最陡**的方向決定上限：一旦在那個方向上一步跨過谷底、而且跨得比原來還遠，那個方向的誤差就開始每步放大。
- 走完全程的時間由**最平**的方向決定：那個方向上梯度很小，每一步只挪一點點。

於是你被夾住：$\eta$ 不能大於最陡方向允許的值，但你需要的步數由最平方向決定。**碗越是又長又窄，這個夾擊越痛苦。** 「又長又窄」的量化就是條件數 $\kappa=\lambda_{\max}/\lambda_{\min}$。

實務上讓碗變窄的最常見原因既不是模型也不是資料量，而是**特徵的尺度不一致**：一個特徵是「坪數」（$10$–$80$），另一個是「房間數」（$1$–$5$），第三個是「屋齡」（$0$–$40$）。同樣把權重動一單位，對損失的影響差了幾十倍——碗就被拉成細長的溝。這也是為什麼「標準化特徵」是幾乎所有教學裡的第一步，卻很少解釋為什麼：**它在改碗的形狀，不是在美化數字。**

## 一步走多大會開始發散

取最乾淨的情形：線性模型 $f_w(x)=\phi(x)^\top w$、平方損失。令 $V$ 是設計矩陣（第 $i$ 列是 $\phi(x_i)^\top$），

$$
L(w)=\frac1n\lVert Vw-y\rVert^2,
\qquad
\nabla L(w)=\frac{2}{n}V^\top(Vw-y),
\qquad
\nabla^2 L=\frac{2}{n}V^\top V\ \ (\text{常數}).
$$

Hessian 是常數，所以這個碗**就是**二次的，沒有高階項要擔心。令 $H=\frac1nV^\top V$，其特徵值 $0\le\lambda_{\min}\le\dots\le\lambda_{\max}$，最小點 $w^\star$。把誤差 $e_k=w_k-w^\star$ 投影到 $H$ 的特徵向量上，第 $j$ 個分量的遞迴是

$$
e_{k+1}^{(j)}=(1-\eta\lambda_j)\,e_k^{(j)}.
$$

**每一步就是乘上一個常數。** 於是一切都清楚了：

$$
\text{收斂}\iff |1-\eta\lambda_j|<1\ \ \forall j
\iff \boxed{\ 0<\eta<\frac{2}{\lambda_{\max}}\ }
$$

而收斂**速度**由最慢的那個分量決定，也就是 $\lambda_{\min}$ 那個方向。在最佳的 $\eta=\frac{2}{\lambda_{\max}+\lambda_{\min}}$ 下，每步的收縮率是

$$
\frac{\kappa-1}{\kappa+1},\qquad \kappa=\frac{\lambda_{\max}}{\lambda_{\min}}.
$$

$\kappa=1$（正圓的碗）：一步到位。$\kappa=10^7$（下面實測會遇到）：收縮率是 $0.9999998$——**每一步只前進千萬分之二。** 這就是為什麼一個「有在收斂」的訓練仍然可以慢到沒有用。

<Remark label="注意" summary="為什麼發散是指數的，而且看起來很突然">
跨過門檻時，某個方向的乘數 $|1-\eta\lambda_{\max}|$ 從 $0.99$ 變成 $1.04$。$2000$ 步之後，$1.04^{2000}\approx10^{34}$。損失是誤差的平方，於是你看到 $10^{68}$ 甚至更大——實測是 $6.6\times10^{122}$。

這解釋了兩個實務現象。一，**發散通常表現成「訓練了幾百步都好好的，然後突然 NaN」**：指數成長在前期看不出來，直到超過浮點數上限。二，**門檻附近沒有安全邊際**：$\eta$ 從 $1.05$ 調到 $1.15$（不到 $10\%$）就從收斂變成炸掉。所以實務建議是「先找會炸的 $\eta$，再退回三到十倍」，而不是在門檻邊緣求極限效能。

非二次的目標（真正的神經網路）沒有常數 Hessian，$\lambda_{\max}$ 會隨著訓練變動，於是門檻是會移動的——一個一開始安全的 $\eta$ 可能在訓練中途變得不安全。這是 warmup 與學習率 schedule 的動機之一，屬於 <Ref to="ml-optimizers" mode="title"/>。
</Remark>

## 回到情境：門檻不是建議值，是懸崖

**這一切依賴什麼。** 一，損失對參數可微（所以 $0$–$1$ 錯誤率不能直接用，得換成 <Ref to="ml-loss-declaration" mode="title"/> 裡的替代損失）。二，二次分析要求 Hessian 固定；一般模型只在局部近似成立，因此門檻是局部的。三，這裡算的是**全批次**梯度——每一步都用上全部資料。實務上用 minibatch，梯度帶噪聲，穩定性的討論要修改，那是 <Ref to="ml-minibatch-noise" mode="title"/>。

**一個常見的誤解值得先破。** 「學習率調小總是比較安全」在穩定性上對，在實務上錯：$\kappa$ 大的時候，太小的 $\eta$ 會讓你在預算內根本走不到有用的地方——下面 $\eta=0.01$ 跑 2000 步的訓練誤差 $0.209$，比只用一條直線擬合還差。

> **沒收斂與發散一樣是失敗，只是它不會給你 NaN 這種明顯的訊號。**

## 回到情境：把門檻跑出來

用共用 toy 與五次多項式特徵。這個問題有直接解，所以我們知道終點在哪裡：

```python
import numpy as np
from ml_toy import toy_1d

x, y = toy_1d()
V = np.vander(x, 6, increasing=True)                 # 1, x, …, x^5
print(f"直接解的訓練 MSE = {((V@np.linalg.lstsq(V, y, rcond=None)[0] - y)**2).mean():.4f}")

lam = np.linalg.eigvalsh(V.T @ V / len(x))
print(f"λmax = {lam[-1]:.4f}   門檻 η* = 2/λmax = {2/lam[-1]:.3f}   條件數 = {lam[-1]/lam[0]:.1e}")

for eta in (0.01, 0.1, 0.5, 1.05, 1.15):
    w = np.zeros(6)
    for _ in range(2000):
        w -= eta * (V.T @ (V @ w - y)) / len(x)      # 全批次梯度下降
    print(f"  η={eta:<5}  2000 步後訓練 MSE = {((V@w - y)**2).mean():.4e}")
```

```
直接解的訓練 MSE = 0.0147
λmax = 1.8034   門檻 η* = 2/λmax = 1.109   條件數 = 1.6e+07

  η=0.01   2000 步後訓練 MSE = 2.0935e-01
  η=0.1    2000 步後訓練 MSE = 1.4498e-01
  η=0.5    2000 步後訓練 MSE = 7.0104e-02
  η=1.05   2000 步後訓練 MSE = 4.1486e-02
  η=1.15   2000 步後訓練 MSE = 6.6166e+122
```

三件事：**門檻是真的**（$1.05$ 收斂、$1.15$ 是 $10^{122}$，理論值 $1.109$ 正好夾在中間）；**大 $\eta$ 在門檻以下一律比較好**（$0.01\to0.5\to1.05$ 單調變好）；**但即使用了幾乎最大的合法步伐，2000 步後仍然是 $0.0415$ 而不是 $0.0147$**——被條件數 $1.6\times10^7$ 卡住。加步數也救不了：以那個收縮率，要靠近直接解需要的步數是天文數字。

**刻意違反：只換單位。** 同一個問題，把 $x$ 從「$0$ 到 $1$」改成「民國 $100$ 到 $110$ 年」——這在真實資料裡是完全正常的事，沒有人會覺得自己做了什麼：

```python
t = 100 + 10*x                                        # 同一份資料，換一個單位
Vt = np.vander(t, 6, increasing=True)
lam_t = np.linalg.eigvalsh(Vt.T @ Vt / len(t))
print(f"λmax = {lam_t[-1]:.3e}   門檻 η* = {2/lam_t[-1]:.3e}")
for eta in (0.01, 1e-12, 1e-24):
    w = np.zeros(6)
    for _ in range(2000):
        w -= eta * (Vt.T @ (Vt @ w - y)) / len(t)
    print(f"  η={eta:<8}  2000 步後訓練 MSE = {((Vt@w - y)**2).mean():.4e}")
```

```
λmax = 1.750e+20   門檻 η* = 1.143e-20
  η=0.01      2000 步後訓練 MSE = nan
  η=1e-12     2000 步後訓練 MSE = nan
  η=1e-24     2000 步後訓練 MSE = 3.9465e-01
```

**可用的學習率縮小了二十個數量級。** 因為 $t^5\approx10^{10}$，那一欄的尺度支配了整個 Hessian。$\eta=0.01$ 直接 NaN；勉強能跑的 $10^{-24}$ 在 2000 步後幾乎沒有移動（$0.39$，比直線還差）。**模型沒變、資料沒變、目標沒變，只是換了一個單位，訓練就完全壞掉。**

處方是把每一欄拉回同一個尺度：

```python
Vz = np.vander((t - t.mean())/t.std(), 6, increasing=True)
Vz = Vz / np.linalg.norm(Vz, axis=0) * np.sqrt(len(t))     # 每一欄標準化
lam_z = np.linalg.eigvalsh(Vz.T @ Vz / len(t))
print(f"λmax = {lam_z[-1]:.3f}   η* = {2/lam_z[-1]:.3f}   條件數 = {lam_z[-1]/lam_z[0]:.1e}")
w = np.zeros(6)
for _ in range(2000):
    w -= 0.3 * (Vz.T @ (Vz @ w - y)) / len(t)
print(f"  η=0.3   2000 步後訓練 MSE = {((Vz@w - y)**2).mean():.4f}")
```

```
λmax = 3.936   η* = 0.508   條件數 = 1.6e+03
  η=0.3   2000 步後訓練 MSE = 0.0155
```

條件數從 $1.6\times10^7$ 掉到 $1.6\times10^3$，$2000$ 步就走到 $0.0155$——距離直接解的 $0.0147$ 只差一點點，比原始尺度的 $0.0415$ 好得多。之後遇到 BatchNorm、LayerNorm、殘差連接時，它們的第一層動機都是同一件事——讓碗變圓。

> **標準化不是清潔工作，它是在改變最佳化問題的幾何。**

兩個問題的 $\lambda_{\max}$ 相同，但條件數一個是 $10$、一個是 $10^6$。關於它們的訓練：
<Option>兩者可用的最大學習率不同。</Option>
<Option correct>兩者的穩定門檻**相同**（都由 $\lambda_{\max}$ 決定），但收斂到同樣精度所需的步數差了大約五個數量級——條件數決定速度，不決定門檻。</Option>
<Option>條件數大的那個一定會發散。</Option>
<Explanation>
把兩個角色分開是這一篇的核心：$\lambda_{\max}$ 管「會不會炸」，$\kappa=\lambda_{\max}/\lambda_{\min}$ 管「要走多久」。這也解釋了實務上的兩類處方彼此獨立——降 $\eta$ / warmup 對付門檻；標準化、預條件、Adam 的逐參數尺度、殘差與正規化層對付條件數。診斷錯了就會用錯處方：訓練「很慢但穩定」時把學習率再調小，是最常見的一種。
</Explanation>
</QuizBlock>

這一篇把 $\arg\min$ 換成一個迴圈：往負梯度走的理由來自 Taylor 一階項，步伐上限由 $\lambda_{\max}$ 決定（$\eta<2/\lambda_{\max}$，跨過去是 $10^{122}$ 不是「慢一點」），走完的時間由條件數決定。換一個特徵單位就能讓可用學習率縮小 $10^{20}$ 倍，而標準化把它換回來——最佳化的難易度有一大半是你自己的座標選出來的。

L0 到此結束：三個零件（假設空間、損失、資料）加上一個把 $\arg\min$ 真正執行出來的迴圈。但 L0 一路上出現了兩個沒有處理的紅燈——經驗風險壓到接近零卻不是好消息，以及假設空間變大時落差爆炸。下一個 class 專門處理它們：什麼叫過擬合與欠擬合、怎麼在自己的資料上看出是哪一種、以及該怎麼辦。
