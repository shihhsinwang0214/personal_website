> 這些模板不是表格作業。它們存在的理由是：把「想清楚了沒有」變成一件你自己看得出來的事。欄位填不出來，通常就是還沒想清楚的地方。

## 模板一：問題地圖（第 1 週）

```text
問題：我們在處理什麼問題？對應到什麼實際需求？
現況：目前已經知道什麼？（誰做過、結論是什麼）
未知：真正還不知道的是什麼？
指標：怎麼判斷有沒有做到？這個指標真的對應到問題嗎？
假設：這條路線建立在哪些假設上？
我的疑問：我現在最不確定的三件事
```

## 模板二：重現紀錄（第 2 週）

```text
目標結果：來源、參考輸出、可接受誤差
環境：commit / 資料版本 / 套件 / 硬體 / 執行指令
設定：隨機種子、超參數、評估方式、執行時間
實際結果：
差異：目標與實際的落差，以及可能的原因（分成環境、理論、評估三類）
協助來源：用了哪些 AI 或他人協助，哪些部分我親自查證過
```

## 模板三：最小實驗卡（第 3 週）

```text
觀察：我看到什麼？原本預期什麼？
問題：這個落差形成什麼問題？
可能解釋 A：
可能解釋 B：
區分方式：如果 A 成立我會看到＿＿；如果 B 成立我會看到＿＿
實驗設計：用什麼 toy example / ablation / 控制變因
判讀標準：成功、失敗、無法判讀分別長什麼樣
預算：時間、運算
停損點：什麼情況下暫停或縮小
```

## 模板四：Checkpoint 紀錄

```text
日期：
上次之後做了什麼：
學到什麼（包含失敗的）：
現在卡在哪：
下一步（最有資訊量的那一個）：
需要什麼協助：
```

## 模板五：月底報告結構

```text
Motivation：我在看什麼問題？為什麼重要？
Limitation：現有方法漏掉什麼？我用什麼 toy example 說明？
Solution：我試了什麼？為什麼這樣想？
Progress：什麼失敗了？我卡在哪？為什麼？
搞砸的部分：哪裡走錯、怎麼發現的
貢獻界線：哪些是我做的、哪些是工具或他人協助
下一步與理由：
```
