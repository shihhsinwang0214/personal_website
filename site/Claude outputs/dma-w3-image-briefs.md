## 0. 共用風格規範（每一張都要遵守）

- **要跟 `w-3-0-2.png` 看起來像同一套**：淺色底（近白 `#fffdfb`）、細邊框圓角面板、大量留白、扁平（不要陰影、不要漸層背景、不要 3D 光澤）。
- **配色固定三色**：噪聲／高斯＝藍 `#4a90e2`；資料＝橘 `#f0803c`；強調與箭頭＝靛藍 `#2a4ea3`。灰階用於次要標註。**不要彩虹色盤。**
- **標註語言：繁體中文**，無襯線字體，字要大到縮到單欄寬（約 700px）還讀得清楚。數學符號用簡單上下標（`x_t`、`√ᾱ_t`、`σ_t`、`E[x₀|x_t]`），不要試著排 LaTeX。
- **中文字不能寫錯或缺字**（生圖模型常出這個問題）；如果模型畫不出可靠的中文，就把文字留空、由我們後製加上。
- 照片素材：用**動物或靜物**（貓、鳥、兔、盆栽），**不要出現真人臉**、不要品牌與可辨識商標。
- 輸出：PNG，寬 1600–2000px，長寬比照各張指定；淺底不要透明。

## 1. `w3-1-1.png` — 加噪的階梯（W3.1 開場）

**目的**：讓讀者一眼看到「forward 很容易、reverse 才是要學的」。

**畫面**：一排 7 格等寬縮圖，**同一張真實照片**（例如一隻貓）逐步加噪：
`t=0`（原圖）→ `t=100` → `t=250` → `t=400` → `t=600` → `t=800` → `t=1000`（純雜訊）。

- 每格下方標 `t=…`；在 `t=0`、`t=400`、`t=1000` 三格多標一行 `√ᾱ_t = 1.00 / 0.44 / 0.03` 與 `σ_t = 0.00 / 0.90 / 1.00`。
- 縮圖**上方**一條向右的粗箭頭（橘）：`forward：加一點點噪聲——我們本來就會做`
- 縮圖**下方**一條向左的細箭頭（藍）：`reverse：去噪——這才是要學的`
- 右下角一句：`往右每一步都很容易；往左一整步很難，但一小步不難。`

**長寬比**：約 16:6（很寬的一條）。

## 2. `w3-2-1.png` — 同一個 x_t 可以來自很多張圖（W3.2）

**目的**：說明 $L_2$ 的最佳解是條件期望，以及「$t$ 大時輸出模糊是正確答案」。

**畫面**：上下兩排，共用「左：候選原圖 → 中：$x_t$ → 右：模型的最佳輸出」的結構。

- **上排（$t$ 小）**：左邊 3 張候選照片，只有 1 張亮著、另 2 張灰掉；中間是輕微加噪的 `x_t`；右邊輸出幾乎等於那張原圖，清楚。
- **下排（$t$ 大）**：左邊 5 張**不同**的照片（不同的貓、鳥、兔）全部亮著，各用一條線連到中間**同一張**糊到看不出內容的 `x_t`，線的粗細代表後驗權重；右邊輸出是這 5 張的加權平均——一張灰灰的四不像。
- 標註：中間 `x_t`；右邊 `E[x₀ | x_t]`；下排右邊加一句 `這不是訓練失敗，這就是 L₂ 的最佳解`。
- 底部一句：`t 越大，能變成同一個 x_t 的原圖越多，平均起來就越模糊。`

**長寬比**：約 4:3。

## 3. `w3-3-1.png` — 同一個方向，但 t 太大時 x̂₀ 退化（W3.3）

**目的**：把 Tweedie 公式（方向相同、長度差 $\sigma_t^2$）與「太 noisy 時估不準長什麼樣」同時講掉。

**畫面**：左右兩塊。

- **左塊「同一個方向」**：一片有**等高線**的地形（兩個峰），上面一個點 `x_t`；從它畫出兩支**重疊**的箭頭——一支細長標 `∇log p_t`、一支短粗標 `√ᾱ_t·E[x₀|x_t] − x_t`；旁邊標 `方向相同，長度差 σ_t²`。
- **右塊「t 一大就退化」**：三張並排的 `x̂₀` 縮圖，對應 $t$ 小／中／大：清楚的貓 → 有點糊的貓 → 幾乎是整個資料集的「平均臉」（看不出是什麼動物）。三張下面各標 `t=100 / 500 / 900`。
- 右塊下方一句：`Tweedie 公式沒有變壞，是 x_t 裡的資訊變少了——t 大時後驗很寬，條件期望本來就會靠向整體平均。`
- 底部一句：`x̂₀ 模糊不是估錯，而是這個 t 能知道的就這麼多；取樣靠很多小步把它逐漸變清楚。`

**長寬比**：約 16:9。

## 4. `w3-4-1.png` — 同一組邊際，兩種走法（W3.4）

**目的**：讓「邊際相同、軌跡不同」不必靠相信。

**畫面**：一張時空圖。

- 橫軸＝時間（**右邊 $t=1$、左邊 $t=0$**，另加一個指向左的箭頭表示取樣方向）；縱軸＝1D 的資料空間。
- 背景是 `p_t(x)` 的熱圖（單色漸層，藍→橘）：右端一團寬的高斯，往左慢慢分裂成兩個窄峰。
- 疊兩組軌跡，從**同一批起點**出發：上半是抖動的折線（標 `reverse SDE（DDPM）`），下半是光滑曲線（標 `PF-ODE（DDIM）`），兩組都收在同樣的兩個峰上。
- 左端（$t=0$）各附一個小直方圖，兩者**看起來一樣**，中間放一個等號並標 `邊際相同`；中段標 `軌跡不同`。
- 底部一句：`差別不在最後停在哪裡，而在路上抖不抖——這也是為什麼步數少的時候兩者會分出高下。`

**長寬比**：約 16:9。

## 5. `w3-5-1.png` — loss 的下界隨 t 走（W3.5）

**目的**：解釋「loss 停在 0.3 不動」不是 bug。

**畫面**：主圖是一張折線圖，橫軸 $t$（0→1000）、縱軸 loss（0→1.1），畫三樣東西：

1. 一條**橘色實線**＝理論下界（$\epsilon$ 給定 $x_t$ 的條件變異數），從接近 0 平滑爬到接近 1；
2. 一堆**藍色散點**＝實際訓練依 $t$ 分箱得到的 loss，貼在那條線上方一點；
3. 一條**水平虛線**標 `所有 t 平均起來 ≈ 0.3`，並註明 `就是你在 log 裡看到停住的那個數字`。

左右各一個小插圖：

- 左（$t$ 小）：`x_t` 幾乎是原圖，旁註 `看到 x_t 幾乎就知道 ε → 下界接近 0`
- 右（$t$ 大）：`x_t` 幾乎是純雜訊，旁註 `ε 給定 x_t 仍接近 N(0,I) → 下界接近 1`

底部一句：`loss 停住不是 bug；真正該看的是這條隨 t 變化的曲線。`

**長寬比**：約 16:9。
