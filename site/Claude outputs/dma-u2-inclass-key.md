# 課堂練習解答與帶法（教師用）

**一句話說這個練習在做什麼**：讓學生自己算出「一步 flow matching 會把所有起點塌成一個點」，再自己算出「兩步就幾乎分對邊」，然後說出多的那一步買到了什麼。
全程紙筆，不需要電腦，每一步都有閉式解。

---

## 為什麼是這個設定

$p_1$ 取兩個點、$p_0$ 取一維高斯、path 取直線——這是**唯一一個 $v_t^\star$ 有初等閉式解、而且答案不平凡**的組合。
兩個點給出 $\tanh$；再多一個點就要算 softmax，手算就崩了。一維讓他們畫得出來。

---

## 完整解答

### Part A（通式，三行，不需要任何假設）

$$I_t=(1-t)X_0+tX_1\ \Longrightarrow\ X_0=\frac{x-tX_1}{1-t}$$
$$\dot I_t=X_1-X_0=X_1-\frac{x-tX_1}{1-t}=\frac{(1-t)X_1+tX_1-x}{1-t}=\frac{X_1-x}{1-t}$$
$$\boxed{\,v_t^\star(x)=\frac{\mathbb E[X_1\mid I_t=x]-x}{1-t}\,}$$

**這裡要停下來講的**：整段推導沒有用到 Gaussian、沒有用到獨立配對，只用了 $I_t$ 的定義。
它和 <U2.3> 對 VP path 做的是**同一個手法**——先用位置把一個端點消掉，再取條件期望。學生做完這題就等於把那一篇的方法練了一遍。

### Part B（後驗）

給定 $X_1=s$：$I_t\sim\mathcal N\!\big(ts,\,(1-t)^2\big)$。Bayes 取比值、log 之後高次項全消：

$$\log\frac{P(+1\mid x)}{P(-1\mid x)}=-\frac{(x-t)^2-(x+t)^2}{2(1-t)^2}=\frac{2tx}{(1-t)^2}$$

$$\boxed{\,\mathbb E[X_1\mid I_t=x]=\tanh\!\Big(\frac{tx}{(1-t)^2}\Big)\,}$$

合起來：$v_t^\star(x)=\dfrac{1}{1-t}\Big[\tanh\big(\tfrac{tx}{(1-t)^2}\big)-x\Big]$。

### Part C（走）

**C1（$N=1$）.** $t=0$ 時 $I_0=X_0$，所以條件就是 $X_0=x$；獨立配對 ⇒ $\mathbb E[X_1\mid X_0=x]=\mathbb E[X_1]=0$（$\tanh(0)=0$ 也對得上）。
$$v_0^\star(x)=\frac{0-x}{1-0}=-x\ \Longrightarrow\ x_1=x_0+1\cdot(-x_0)=\boxed{0}$$
**每一個起點都落在 0。** 整個 $\mathcal N(0,1)$ 被壓成一個點。

**C2（$N=2$）.** 第一步：$x_{1/2}=x_0+\tfrac12(-x_0)=\tfrac{x_0}{2}$。
第二步：$v_{1/2}^\star(y)=2\big[\tanh(2y)-y\big]$，代 $y=\tfrac{x_0}{2}$：
$$x_1=\frac{x_0}{2}+\frac12\Big(2\tanh(x_0)-x_0\Big)=\frac{x_0}{2}+\tanh(x_0)-\frac{x_0}{2}=\boxed{\tanh(x_0)}$$
兩個 $\tfrac{x_0}{2}$ **剛好消掉**——這一步算出來的時候通常會有人笑出來，值得讓他們自己撞到。

**C3 完整表格**

| $x_0$ | $N=1$ | $N=2$ | $N=4$ | $N=8$ | 真值 |
|---|---|---|---|---|---|
| $2$ | $0$ | $0.9640$ | $1.0000$ | $1.0000$ | $+1$ |
| $0.8$ | $0$ | $0.6640$ | $1.0000$ | $1.0000$ | $+1$ |
| $0.2$ | $0$ | $0.1974$ | $0.9743$ | $1.0000$ | $+1$ |
| $0.05$ | $0$ | $0.0500$ | $0.5002$ | $1.0000$ | $+1$ |

（$N=2$ 那一欄就是 $\tanh(x_0)$。表中數值以閉式 $v_t^\star$ 逐步 Euler 算出，已數值核對。）

### Part D（要交的那一句）

**標準答案**：多的那一步買到的是**後驗解析度**。

$N=1$ 時唯一用到的條件是 $I_0=x$，而 $I_0=X_0$——這個條件對 $X_1$ **一點資訊都沒有**（獨立配對），所以後驗就是先驗，平均就是全體平均 0。
只要走出第一步，位置裡就混進了 $tX_1$ 這一項，$I_t=x$ 開始能分辨 $X_1$ 是 $+1$ 還是 $-1$，後驗才開始往一邊倒。$\tanh$ 的宗旨就是這個：$\frac{tx}{(1-t)^2}$ 越大，越確定。

**可以接受的其他講法**：「第一步只知道自己從哪來，第二步才開始知道自己要去哪」「步數在買資訊，不是在買精度」。

**不接受**：「因為 Euler 誤差變小」。這題的模型是**精確的**，$N=1$ 的失敗不是離散化誤差大小的問題——它是一個**結構性的塌陷**，多一步之所以有救，不是因為步長小了一半。

## 帶法（30 分鐘）

| 時間 | 做什麼 |
|---|---|
| 0–2 | 講設定，然後**先讓他們猜 $N=1$ 的答案**（舉手或 Kahoot）。多數人會說「落在某個資料點」或「落在 +1 附近」 |
| 2–10 | Part A。走動看一下，卡住的人通常是不敢把 $X_0$ 解出來——提示「$I_t=x$ 是一條方程式，$X_0$ 可以被消掉」 |
| 10–17 | Part B。卡住的點是不知道給定 $X_1=s$ 之後 $I_t$ 的變異數是 $(1-t)^2$ |
| 17–26 | Part C。C1 算完先停 30 秒，讓「每個人都落在 0」這件事沉下去，再放他們算 C2 |
| 26–30 | 收 Part D。挑兩張念出來，一張對的、一張說「Euler 誤差變小」的 |

**Part A 之後最值得插的一句**：這條推導沒有用到 Gaussian、沒有用到獨立——所以它對任何 $p_1$、任何配對都成立。U2 的核心定理也是這樣，一次都沒用到高斯。

---

## 兩個延伸題的答案

**1. 哪一段 $x_0$ 最需要步數？** $x_0$ 接近 0 的那一段。後驗 $\tanh\big(\tfrac{tx}{(1-t)^2}\big)$ 在 $x\approx0$ 附近最平——那裡的粒子最久分不出自己該去 $+1$ 還是 $-1$，$v_t^\star$ 也在那裡轉得最急。這正好預告 U3：**要走幾步，是由「軌跡在哪裡彎」決定的，而不是全程一致。**

**2. 把兩點拉到 $\pm3$，$N=2$ 會變好還是變壞？** 變好。重做 C2：$v_0^\star(x)=-x$ 不變（平均仍是 0），所以 $x_{1/2}=\tfrac{x_0}{2}$；第二步的後驗變成 $3\tanh\big(\tfrac{3\cdot 0.5\cdot y}{0.25}\big)$，終點是 $3\tanh(3x_0)$。$x_0=0.2$ 時 $3\tanh(0.6)=1.61$（目標 3，還差得多），但相對誤差比原本小——**兩個 mode 離得越開，後驗越早分得出來**。
這一題的價值在於它讓「模糊區有多大」變成一個可以調的旋鈕。

## 如果教室有電腦（可選，5 行）

```python
import numpy as np
v = lambda x,t: (np.tanh(t*x/(1-t)**2)-x)/(1-t) if t>0 else -x
def euler(x0,N):
    x,h = float(x0), 1.0/N
    for k in range(N): x += h*v(x,k*h)
    return x
print([round(euler(2.0,N),4) for N in [1,2,4,8,32]])
```

但**建議不要先給**。手算 C2 的時候那兩項消掉，是這 30 分鐘最好的一刻。
