# Slido 五題（每題 60 秒）

**出題模式**：題幹先把情境釘死（已經訓到什麼程度、正在做什麼、量到了什麼），
**四個選項每一個都是某個情境下的正解**，但只有一個對應題幹寫的這個情境。
所以誤答診斷的是「他以為自己在哪個情境」，不是知不知道——下面每一題都標出每個錯答**在什麼情況下才對**，那是討論時最有用的東西。

配比：FM 兩題、FM↔diffusion 一題、reflow／minibatch／Heun 兩題。

## Q1 · Flow Matching

> 直線 path、獨立配對，模型已經訓到 loss 不再下降。
> 用 **8 步** Euler 生成，終點分布明顯偏離 $p_1$。你把步數加到 **200 步**，偏差幾乎消失。
> **根據這個實驗，哪一個診斷最站得住？**

| | 選項 | 這個選項在什麼情況下才對 |
|---|---|---|
| A | 模型學到的 velocity 還不夠準 | 加步數**沒有**改善的時候。模型誤差有一個地板，步數吃不掉 |
| **B** | **離散化誤差：軌跡是彎的，8 步的 Euler 跟不上** ✅ | **就是這題**——加步數就好了，只有離散化誤差有這個性質 |
| C | 評估用的樣本數不夠，是蒙地卡羅雜訊 | 偏差落在誤差棒之內的時候。該先檢查這個再相信任何結論 |
| D | 配對太亂，conditional velocities 在同一點衝突 | 你**換了配對再比一次**的時候。D 是 B 的成因，但這個實驗分辨不出來 |

**為什麼**：三種誤差各自對一種操作有反應——模型誤差對「訓更久／更大」、離散化誤差對「加步數」、雜訊對「加樣本」。
題幹只做了「加步數」這一個操作，所以它只能支持 B。

**答完說一句**：D 很多人會選，而且它**不算錯**——交叉確實是軌跡變彎的原因。但它是 B 的上游，要證明它得再做一個實驗（換成 OT 配對，看同樣 8 步有沒有變好）。這就是下一題。

## Q2 · Flow Matching

> 兩組配對，$p_0$、$p_1$ 完全相同。
> **甲**：所有軌跡都是不交叉的等速直線，$S(\pi)=0$，但 transport cost $=4.0$。
> **乙**：$S(\pi)>0$，transport cost $=0.4$。
> 用**一步** Euler 生成，誰的終點分布比較接近 $p_1$？

| | 選項 | 這個選項在什麼情況下才對 |
|---|---|---|
| A | 這種情況不可能，$S=0$ 就等於 OT 配對 | **一維**。1-D 裡不交叉 ⟺ 單調 ⟺ 凸成本的 OT，所以 A 在一維是對的 |
| **B** | **甲比較好——$S=0$ 代表一步 Euler 精確** ✅ | **就是這題**（二維以上） |
| C | 乙比較好，cost 小代表搬得少、比較好學 | 比較「訓練難度」或「需要多少容量」的時候 |
| D | 兩個一樣，配對不影響終點分布 | 比較**連續時間、精確 velocity** 下的終點時。那時兩個都給 $p_1$ |

**具體例子**（可以直接寫黑板）：$p_0=p_1=\mathcal N(0,I)$，二維。
**甲** ＝ 每個點配給「旋轉 90° 後的自己」。軌跡 $x_t=\big((1-t)I+tR\big)x$，$\det=(1-t)^2+t^2>0$，**映射始終可逆 ⇒ 不交叉 ⇒ $S=0$**，cost $=\mathbb E\|Rx-x\|^2=4.0$。
**乙** ＝ 90% 配給自己、10% 配給旋轉後。cost $=0.4$，但同一點出現兩種速度 ⇒ $S>0$。
一步 Euler：甲是 $x\mapsto Rx$，變異數 $(1.00,1.00)$ ✅；乙是 $x\mapsto 0.9x+0.1Rx$，變異數 $(0.82,0.82)$ ❌。

**答完說一句**：**直不等於最省。** straightness 問「每一對能不能等速直走」，OT 問「所有配對裡哪一種最省」。這也是 reflow 和 minibatch OT 在追不同東西的原因。

## Q3 · Flow Matching 與 Diffusion 的關係

> 你手上有一個在 **VP path** 上訓好的 $\epsilon_\theta$。你用
> $v=\tfrac{\dot\alpha}{\alpha}x+\big(\dot\sigma-\tfrac{\dot\alpha}{\alpha}\sigma\big)\epsilon_\theta$
> 把它換成 velocity，再拿去解 ODE。
> **下面四件事，哪一件做了會讓結果失效（不是變慢或變不準，是模型被用在它沒看過的地方）？**

| | 選項 | 這個選項在什麼情況下才是該擔心的 |
|---|---|---|
| A | 把 solver 從 Euler 換成 Heun | 你在算 NFE 預算的時候。換 solver 完全合法 |
| B | 把時間格點從 1000 個減到 20 個 | 你在壓取樣成本的時候。會變不準，但仍然合法 |
| **C** | **把 $(\alpha_t,\sigma_t)$ 換成直線 path 的 $(t,\,1-t)$** ✅ | **就是這題**——換 path 就換了中間的 $p_t$ |
| D | 把 velocity 再換算回 score 來用 | 你想加 Langevin 修正項的時候。同一條 path 上的座標換算，合法 |

**為什麼**：A、B、D 動的都是**取樣器**或**輸出座標**；C 動的是**網路輸入的分布**。
$\epsilon_\theta$ 估的是 $\mathbb E[\epsilon\mid I_t=x]$，而這個條件期望綁在訓練時那條 $p_t$ 上。換了 $(\alpha_t,\sigma_t)$，同一個 $(x,t)$ 對應的 $p_t$ 就不同了，網路會被餵到它沒看過的地方。

**答完說一句**：**不用重訓能換的是表示方式（noise／score／velocity），不是中間的 probability path。** 這條線在整門課會一直回來。

## Q4 · reflow

> 你跑了一輪 reflow。新模型在 **1 步生成**上明顯變好，
> 但在 **100 步生成**上反而比原模型**差一點**（差距遠大於誤差棒）。
> **最可能的解釋是？**

| | 選項 | 這個選項在什麼情況下才對 |
|---|---|---|
| A | reflow 改變了 $p_1$，所以 100 步也救不回來 | 實作有 bug 的時候。理想 ODE 下 rectification **保邊際**，這是可以證的 |
| **B** | **新配對是用「原模型的 ODE」造的，原模型的誤差被寫進了新的訓練資料** ✅ | **就是這題**——1 步變好（更直）而 100 步變差（上限被拉低） |
| C | 差距是蒙地卡羅雜訊 | 差距落在誤差棒內的時候。題幹已經排除 |
| D | 新的配對比較難學，網路容量不夠 | 你換大網路就補得回來的時候 |

**為什麼**：reflow 的新配對是 $(X_0,Z_1)$，而 $Z_1$ 是**模型自己積出來的終點**——模型誤差與 solver 離散誤差都在裡面，下一輪把它當成真值。
所以 reflow 買到的是**直**（少步受益），付出的是**上限**（多步時暴露）。這就是實務上只做一到兩輪的原因。

**答完說一句**：minibatch OT 沒有這個問題——它從頭到尾沒呼叫網路。它付的是另一種代價：有限 batch 的指派不等於 population OT。**兩者怕的東西完全不同：一個怕累積，一個怕偏差。**

## Q5 · Heun

> 固定 **NFE 預算 = 40**。手上兩個模型：
> **甲**已經用 reflow 把軌跡拉得很直；**乙**沒有，軌跡仍然很彎。
> 兩邊都可以選「Euler 40 步」或「Heun 20 步」。**最合理的選法？**

| | 選項 | 這個選項在什麼情況下才對 |
|---|---|---|
| A | 兩個都用 Heun 20 步 | 兩邊軌跡都彎、而且夠光滑（$\dddot x$ 不大）的時候 |
| **B** | **甲用 Euler 40 步，乙用 Heun 20 步** ✅ | **就是這題** |
| C | 甲用 Heun 20 步，乙用 Euler 40 步 | 如果「拉直」反而讓高階導數變大——實際上相反 |
| D | 兩個都用 Euler 40 步 | 兩邊都已經很直，或 $\dddot x$ 大到升階不划算的時候 |

**為什麼**：Euler 全域誤差 $\lesssim h\int\|\ddot x\|$，Heun $\lesssim h^2\int\|\dddot x\|$，但 Heun 一步 2 NFE ⇒ **相同 NFE 下 $h$ 要加倍**。
甲已經把 $\int\|\ddot x\|$ 壓小了，Euler 本來就夠準，把 40 NFE 全花在步數上更划算；乙的積分大，升階才有賺。
推到極限：$S=0$ 時軌跡是等速直線，$x_1=x_0+1\cdot(X_1-X_0)=X_1$，**Euler 一步就精確**，Heun 花兩倍 NFE 得到一模一樣的答案。

**答完說一句**：**「拉直軌跡」和「用高階 solver」是互相吃掉的，不是可以疊加的兩份收益。** 預算有限時先問一句：我的軌跡已經多直了？

Q4 → Q5 也是一條線（reflow 買到直、付出上限 → 那直了之後 solver 該怎麼選）。
Q3 放中間當 U1 與這週的接點。
