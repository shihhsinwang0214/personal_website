## Q1 · 所有人以同一個常數速度 c 移動，distribution 會怎麼變？ 〔30 秒〕

**正解：形狀完全不變，只是整體平移了 c·t**

一行代入 continuity equation：$\partial_t p=-\nabla\cdot(pc)=-c\cdot\nabla p$，解是 $p_t(x)=p_0(x-ct)$。

| 誤答 | 它診斷什麼 |
|---|---|
| **完全不動，因為 ∇·v=0** | **最值得停的一個，而且前半是對的。** $\nabla\cdot v$ 確實是 0——但 continuity equation 裡的是 $\nabla\cdot(p\,v)$，不是 $\nabla\cdot v$。速度場沒有膨脹壓縮，不代表**某一個固定位置**的 density 不變；整團人走過去了 |
| **擴散變平** | 把「移動」直接聯想成「擴散」。擴散需要隨機性，這裡是純 transport |
| **壓縮變尖** | 同上的反向 |

**答完說一句**：density 會不會變，看的是 flux 的 divergence，不是速度的 divergence。這個區分整個單元都要用。

## Q2 · VP path 的 reference velocity 也是常數嗎？ 〔60 秒〕

**正解：不是，α̇ₜX₁+σ̇ₜε 的兩個係數都隨 t 變**

直接微分：$I_t=\alpha_tX_1+\sigma_t\epsilon \Rightarrow \dot I_t=\dot\alpha_tX_1+\dot\sigma_t\epsilon$。
VP 要求 $\alpha_t^2+\sigma_t^2=1$，所以 $(\alpha_t,\sigma_t)$ 走的是單位圓上的一段弧——**不可能兩個都線性**，$\dot\alpha_t$、$\dot\sigma_t$ 一定隨 $t$ 變。

| 誤答 | 它診斷什麼 |
|---|---|
| **是，端點固定就固定了** | 把直線的性質當成通則。直線之所以速度恆定，是因為係數 $(1-t,t)$ 剛好線性 |
| **不是，因為 ε 每一步重抽** | **真正的誤解。** path 上的 $\epsilon$ 是**一次抽定**的端點，不是 DDPM 取樣時每步注入的新噪聲。這兩個 $\epsilon$ 完全不同 |
| **只有 t≈0.5 是常數** | 「常數」不是逐點性質 |

**答完說一句**：所以「conditional path 是直的」不是 flow matching 的必然，是**直線這個選擇**給的。U2.3 那條 VP path 連還沒平均就已經是彎的了——這和下週要談的「平均之後才變彎」是兩個不同的彎。

## Q3 · 獨立配對、訓到最佳，一步 Euler（h=1）會落在哪？ 〔60 秒〕

**正解：不管從哪裡出發，都落在同一點——資料的平均**

三行：
1. $t=0$ 時 $I_0=(1-0)X_0+0\cdot X_1=X_0$，所以條件「$I_0=x$」就是「$X_0=x$」。
2. $v_0^\star(x)=\mathbb E[X_1-X_0\mid X_0=x]=\mathbb E[X_1\mid X_0=x]-x$。**獨立配對** ⇒ $=\mathbb E[X_1]-x$。
3. 一步 $h=1$：$x+1\cdot(\mathbb E[X_1]-x)=\mathbb E[X_1]$。

跟 $x$ 完全無關。（在 two-moons toy 上實測過：三個相距很遠的起點，一步之後都落在 $(0.502,0.250)$，正是資料平均。）

| 誤答 | 它診斷什麼 |
|---|---|
| **落在和 x₀ 配成一對的資料點** | 把 reference path 當成生成軌跡。訓練時的配對在生成時**不存在**——網路只看得到 $(x,t)$ |
| **落在最近的資料點** | 以為 velocity field 帶有「檢索」的性質 |
| **落在中點** | 算錯步長 |

**答完說一句**（這題的價值）：這就是 U1.0 那個「沒有配對的 L2 會塌成一張平均圖」——**一步 flow matching 就是那張平均圖**。多步之所以有救，是因為走到中途以後 $I_t=x$ 這個條件開始篩掉大部分的 $X_1$，平均才不再是全體平均。

## Q4 · velocity MSE 與 noise MSE，是同一個 objective 嗎？ 〔60 秒〕

**正解：差一個 1/t² 權重，t→0（noise 端）被放大**

兩行代數。在 $I_t=tX_1+(1-t)\epsilon$ 上：
$$\epsilon=I_t-t\dot I_t,\qquad v_\theta=\frac{x-\epsilon_\theta}{t}
\;\Longrightarrow\;
\|v_\theta-\dot I_t\|^2=\frac1{t^2}\|\epsilon_\theta-\epsilon\|^2 .$$
（數值逐項驗過，兩邊相同。）

| 誤答 | 它診斷什麼 |
|---|---|
| **一樣，只是換個座標寫** | **最該抓的。** 換座標保住的是**最佳解**，不是 **objective**。中間多出來的 $1/t^2$ 是一個對 $t$ 的加權，會改變有限預算下訓出來的東西 |
| **差 t²，t→1 被放大** | 記反了。$t\to0$ 是 noise 端，那裡 $v$ 對 $\epsilon$ 的誤差最敏感 |
| **完全無關** | 過度反應 |

**答完說一句**：所以「flow matching 也可以預測 noise」這句話只對了一半——可以，但均勻抽 $t$ 的 velocity MSE 自動帶了一個 $1/t^2$，和 DDPM 的 $\mathcal L_{\text{simple}}$（均勻 noise MSE）不是同一個訓練目標。加權這條線 U3 會整個攤開。

## Q5 · 只換 reference path，vₜ、pₜ、p₁ 哪些會變？ 〔60 秒〕

**正解：vₜ 與 pₜ 都變，只有 p₁ 不變**

回去看 U2.2 那個證明到底保證了什麼。它說的是：每一條 conditional path 各自滿足 continuity equation，加起來仍然滿足——所以沿著 $v_t$ 走會**走完這條 $p_t$**。而 $p_t$ 是誰？就是 $I_t$ 的分布。換了 $I_t$，$p_t$ 就換了，$v_t=\mathbb E[\dot I_t\mid I_t=x]$ 當然也換了。

唯一不動的是兩端——因為我們**設計時就要求** $I_0=X_0$、$I_1=X_1$。

| 誤答 | 它診斷什麼 |
|---|---|
| **三個都不變** | 把 path 當成純粹的視覺輔助 |
| **只有 vₜ 變** | 沒意識到 $p_t$ 就是 $I_t$ 的分布，不是一個獨立存在的東西 |
| **三個都變，所以不能亂換** | 過度保守——而且剛好否定了這個單元最大的賣點 |

**答完說一句**（整組的收尾）：U2.3 那張表列了三個可以自己設計的東西——起點、path、配對。**這一題就是在問那份自由的邊界在哪裡**：中間怎麼走隨你，終點被定理釘死。而「中間怎麼走」影響的是要走幾步——那是下週的事。

## 三題口頭問答（Kahoot 匯入只吃選擇題）

1. **「U2.2 那個證明，從頭到尾有沒有用到 Gaussian？」** 沒有。這件事值得讓他們自己回去翻一次——U1 的每一步幾乎都靠高斯，U2 的核心定理一次都沒用到。
2. **「$v_t$ 被 $p_t$ 唯一決定嗎？」** 不是。任何滿足 $\nabla\cdot(p_tw_t)=0$ 的 $w_t$ 加上去都生成同一條 $p_t$（例如整團人繞圈）。所以 continuity equation 保證「走到哪個 distribution」，不保證「每個人走哪條路」。
3. **「如果你可以自己決定起點和終點怎麼配對，你會怎麼配？為什麼？」** 課前問。他們會自己講出 OT 的直覺，下週再給名字。
