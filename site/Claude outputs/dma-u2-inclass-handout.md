# 課堂練習：一步走完，會走到哪裡？

**30 分鐘・紙筆・可以兩人一組討論**
最後交回來的只有一句話（Part D），其餘是過程。

---

## 設定

- 起點 $X_0\sim\mathcal N(0,1)$（一維）
- 終點 $X_1$ 只有兩個值：$+1$ 和 $-1$，各佔一半
- 兩端**獨立配對**（隨機配）
- Reference path 用直線：$I_t=(1-t)X_0+tX_1$，$t\in[0,1]$
- 假設 velocity network **已經訓到理論最佳解** $v_t^\star$——這一題完全不談模型誤差

生成的方式就是從 $x_0\sim\mathcal N(0,1)$ 出發，用 $N$ 步 Euler 解 $\dot x=v_t^\star(x)$。

---

## 先猜（30 秒，不要算）

$N=1$，也就是**一步走完**。你從 $x_0=2$ 出發，會落在哪裡？

把你的猜測寫下來，等一下回來對。

---

## Part A · 先不看這個例子，推一個通式〔約 8 分鐘〕

只用 $I_t=(1-t)X_0+tX_1$ 這一條式子。

**A1.** 給定 $I_t=x$（且 $t<1$），把 $X_0$ 用 $x$ 和 $X_1$ 表示出來。

**A2.** 把 A1 代進 $\dot I_t=X_1-X_0$，化簡。你應該會得到一個**只含 $X_1$ 和 $x$** 的式子。

**A3.** 兩邊取 $\mathbb E[\;\cdot\mid I_t=x]$，寫出 $v_t^\star(x)$。

> 做完 A3 停一下：這個結果有沒有用到「$X_0$ 是 Gaussian」？有沒有用到「獨立配對」？

---

## Part B · 把這個例子的後驗算出來〔約 7 分鐘〕

A3 把問題縮成一個量：$\mathbb E[X_1\mid I_t=x]$。現在把它算出來。

**B1.** 給定 $X_1=s$（$s=\pm1$），$I_t$ 的分布是什麼？（提示：$I_t=(1-t)X_0+ts$，而 $X_0\sim\mathcal N(0,1)$。）

**B2.** 用 Bayes 寫出 $\dfrac{P(X_1=+1\mid I_t=x)}{P(X_1=-1\mid I_t=x)}$，把兩個 Gaussian 密度相除、取 log。

**B3.** 由 B2 得到 $\mathbb E[X_1\mid I_t=x]$。（答案會是一個 $\tanh$。）

**檢查點**：$t=0.5$、$x=0.4$ 時，$\mathbb E[X_1\mid I_t=x]=0.6640$。$t=0.25$、$x=0.5$ 時是 $0.2186$。

---

## Part C · 走走看〔約 10 分鐘〕

把 A3 和 B3 合起來，你現在有一條完全寫得出來的 $v_t^\star(x)$。

**C1（$N=1$，$h=1$）.** 先算 $v_0^\star(x)$——注意 $t=0$ 時 $I_0=X_0$，所以條件「$I_0=x$」就是「$X_0=x$」。
從 $x_0$ 走一步，落在哪裡？**對每一個 $x_0$ 都算一次**，然後回頭看你一開始的猜測。

**C2（$N=2$，$h=\tfrac12$）.** 走兩步。先算中間點 $x_{1/2}$，再算終點。
（算到最後會有兩項剛好消掉，答案很乾淨。）

**C3.** 把數字填進來：

| $x_0$ | $N=1$ | $N=2$ | $N=4$（給你） | 真正的終點 |
|---|---|---|---|---|
| $2$ | | | $1.0000$ | $+1$ |
| $0.8$ | | | $1.0000$ | $+1$ |
| $0.2$ | | | $0.9743$ | $+1$ |
| $0.05$ | | | $0.5002$ | $+1$ |

（「真正的終點」＝連續時間下這條 ODE 的解。由對稱性，$x_0>0$ 一定走到 $+1$。）

---

## Part D · 要交的那一句〔約 5 分鐘〕

$N=1$ 的時候，每一個起點都落在同一個地方。$N=2$ 的時候就已經幾乎分對邊了。

**用一句話說：多走那一步，到底買到了什麼？**

（提示：比較「$N=1$ 時你在條件什麼」和「$N=2$ 的第二步在條件什麼」。）
