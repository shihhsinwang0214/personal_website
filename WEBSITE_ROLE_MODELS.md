# Website Role Models

This document lists reference websites and knowledge platforms that can inspire the long-term development of this repository.

The goal is NOT to copy any individual website.

Instead, identify strengths worth learning from and adapt them to this repository's needs.

# Repository Direction

This repository should gradually evolve toward:

Lilian Weng
+
Andrej Karpathy
+
Andrew Ng

Meaning:

* Deep research notes (Lilian Weng)
* Practical research engineering (Karpathy)
* Educational impact and accessibility (Andrew Ng)

Avoid becoming:

* A publication-only website
* A CV-only website
* A collection of disconnected notes

Target outcome:

A long-term research knowledge base that also functions as a personal academic website.
