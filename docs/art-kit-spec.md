# Art kit 規格與 prompt

給製作素材的 agent。整份文件可以直接交出去。

**先讀這一段：這裡有兩種產出方式，不要混用。**

| 素材 | 怎麼做 | 為什麼 |
|---|---|---|
| 主視覺（hero） | 圖像生成 | 它是氛圍，點陣圖沒問題 |
| 所有圖表（loop、節點狀態、六步驟） | **手寫 SVG 程式碼** | 要吃 CSS 變數、要能改、要可存取、要在兩套主題下都對 |

圖像模型產出的「SVG」是一堆描圖路徑：改不動、無法跟著主題變色、螢幕閱讀器讀不到、
檔案還比手寫大十倍。**圖表一律手寫。**

---

## 0. 所有素材共同的硬性條件

### 這個網站有兩套主題

```
淺色  --bg #f6f3ee   --surface #fffdfb  --text #1f2733
      --text-muted #646c78  --accent #2a4ea3  --border #e7e0d6

深色  --bg #17181c   --surface #1f2126  --text #e9e6e1
      --text-muted #9a988f  --accent #d8a44a  --border #2c2d31
```

**站主自己用深色。** 任何米白底的點陣圖直接放進深色頁面，就是一塊亮色矩形硬插在
暗背景上。所以：

- 點陣圖 → **交兩個版本**（`-light` / `-dark`），或**完全透明去背**
- SVG → 用 `currentColor` 與 CSS 變數，**不要寫死顏色**

### 其他

- **圖裡不要有任何文字。** 網站是雙語的，圖中文字無法翻譯也無法被搜尋。文字一律由 HTML 疊上去。
- 每張圖都要能給 `width` / `height`（避免版位跳動）與 `loading="lazy"`。
- 交付時附上每個檔案的像素尺寸與檔案大小。
- 遵守 `prefers-reduced-motion`：不要做自動播放的動畫。

## 1. 主視覺 Hero（圖像生成）

**用途**：研究室首頁 `/handbook` 最上方，HTML 的大標題會疊在上面。

**版位**：寬螢幕約 1440×420，右側是圖、左側大量留白給標題。

### Prompt

```
A restrained academic editorial illustration for a research lab website header.

Subject: a long mountain ridge receding into distance, with a small survey camp
in the middle distance — a tent, a tripod telescope, stacked field notebooks,
an open map. A faint path winds from the foreground up toward a distant summit
marker. The scene reads as a long expedition, not a conquest.

Style: fine ink linework with light watercolour wash, in the manner of a 19th
century scientific field journal. Muted, desaturated. Restrained.

Overlay: extremely faint geometric construction lines woven into the terrain —
graph edges between nodes, contour lines, symmetry axes, topology. They must
read as pencil under-drawing, not as a data visualisation or a UI.

Composition: the right 45% holds the terrain and camp; the left 55% is nearly
empty background so a large headline can sit there. Horizon in the lower third.

Palette: cool greys and slate blues, muted sage, warm parchment. No saturated
colour anywhere.

Absolutely exclude: any text, letters, numbers or glyphs; castles, towers with
banners, armour, weapons, magic, glowing crystals, runes; game HUD, buttons,
frames, icons, health bars; people's faces; heavy black outlines; vignette;
lens flare; 3D render look.
```

### 兩個版本

同一個 prompt，末尾各加一句：

- **淺色版**：`Background: flat warm parchment #f6f3ee, uniform, no texture.`
- **深色版**：`Background: flat near-black #17181c. Linework in pale warm grey and muted amber so it reads on a dark background. Same composition and subject.`

深色版**不是**把淺色版調暗——請重新生成，線條要重新配色。

### 交付

```
hero-expedition-light.webp   1440×420  （另附 2880×840 給 2x）
hero-expedition-dark.webp    1440×420  （另附 2880×840）
```

單檔請控制在 **120 KB 以內**。成員頁已經有約 1 MB 的照片，總量要顧。

## 2. Research Refinement Loop（手寫 SVG）

**用途**：`/handbook/how-we-do-research` 與研究室首頁。這是**內容**，不是裝飾——
它畫的是研究室實際在跑的循環，文字版已經寫在 `research-principles`。

**四個節點，順時針**：

```
直覺與觀察  →  toy example  →  證據  →  修正理解
     ↑                                      │
     └──────────────────────────────────────┘
```

再加一條**從「證據」往回指到「直覺與觀察」的虛線**——代表證據常常把你打回問題
formulation，那不是走錯。這條回頭的線是整張圖的重點，不要省略。

### 指令

```
Hand-write an inline SVG (not generated by an image model).

viewBox="0 0 640 260". No fixed width/height attributes.

Four labelled nodes arranged in a horizontal cycle, connected by arrows, plus
one dashed feedback arrow from the third node back to the first, curving below
the row.

Colour rules — no hard-coded colours anywhere:
  strokes and text  : stroke="currentColor" / fill="currentColor"
  accent (arrows, the dashed feedback line) : var(--accent)
  muted labels      : var(--text-muted)
  node fill         : var(--surface)
  node stroke       : var(--border)

Text: leave the four labels as <text> elements with placeholder ids
(#loop-label-1 … #loop-label-4) so the site can inject bilingual strings.
Do NOT bake Chinese or English wording into the file.

Accessibility: <svg role="img"> with <title> and <desc> as the first children.

Stroke width 1.5. Rounded line caps. No gradients, no filters, no drop shadows,
no embedded fonts, no <style> block using hard-coded hex.
```

## 3. Path Node States（手寫 SVG）

**用途**：研究室首頁技能樹的圖例。網站已經實作「讀過的節點會亮」，但目前只有一
句文字說明，缺一個看得懂的圖示對照。

**三種狀態**：未讀（空心）／已讀（實心，accent 色）／目前所在（外圈游標 `▸`）。

### 指令

```
Hand-write an inline SVG. viewBox="0 0 240 40".

Three 7px-radius circles in a row, evenly spaced, each with room for a label
to its right (labels are injected by the site — do not include text).

  1. unvisited : fill var(--surface), stroke var(--border), stroke-width 2
  2. visited   : fill var(--accent), stroke var(--accent)
  3. current   : same as unvisited plus a small triangular cursor to its left,
                 fill var(--accent)

Give each circle an id (#node-unvisited, #node-visited, #node-current).
role="img" with <title> and <desc>. No hard-coded colours.
```

**注意**：這三種狀態必須**不只靠顏色**區分（實心／空心／有無游標），色盲與黑白
列印都要讀得出來。這是網站既有的規則。

## 4. Six-Step Question Loop（手寫 SVG）

**用途**：`/handbook/question-overview`。這一頁的核心訊息是「六個步驟**不是**單向
流水線」，光靠文字很難讓人相信。

**六個節點**：Context → Understand → Analyze → Evaluate → Question → Next Step，
外加**兩條往回的虛線**：Evaluate → Context、Next Step → Evaluate。

### 指令

```
Hand-write an inline SVG. viewBox="0 0 720 300".

Six numbered nodes (01–06) laid out in two rows of three, connected left to
right then wrapping. Two dashed backward arrows curving under the rows:
node 4 → node 1, and node 6 → node 4.

The dashed backward arrows must be visually as prominent as the forward ones —
the point of the diagram is that going back is normal, not an exception.

Numbers 01–06 may be baked in (they are language-neutral). All other text is
injected: leave <text> placeholders with ids #step-label-1 … #step-label-6.

Same colour rules as the Research Refinement Loop. role="img", <title>, <desc>.
```

## 5. 不要製作的東西

以下都被評估過，結論是不做，請不要花時間：

| 提案 | 為什麼不 |
|---|---|
| 六張章節插圖 | 站方規則：每個元素要對應研究室裡真實存在的東西。「建立世界觀」不算。只有能幫讀者理解章節性質或知道自己在哪裡的才做，目前符合的只有上面三張圖表 |
| 申請 checkpoint 插圖 | join 頁已經有 `01 / 02` 的步驟標記，重複 |
| 怪物圖鑑、任務看板的插圖 | 那兩頁的價值在文字索引，加圖只會拉長捲動 |
| 成員頁的插圖 | 用真實照片，已完成 |
| `handbook-art.css` | 網站只有一份手寫的 `global.css` 和一份寫下來的設計系統。請**不要**另外給 CSS 檔——需要的樣式由站方用既有變數寫進 `global.css`，維持單一來源 |
| 任何圖內文字 | 網站雙語 |
| 遊戲 UI 元件（按鈕、框、血條、徽章） | 已有 `.hud` 這套視覺語言 |

## 6. 交付清單

```
hero-expedition-light.webp   +  @2x
hero-expedition-dark.webp    +  @2x
research-loop.svg
path-node-states.svg
question-loop.svg
MANIFEST.md   ← 每個檔案的用途、尺寸、檔案大小，並註明圖像是 AI 生成
```

**不要**附 CSS、不要附 README 的整合指示、不要附 HTML 範例——整合由站方自己做，
因為版面、變數與斷點都在網站這一側。

放進 `site/public/images/handbook/`。
