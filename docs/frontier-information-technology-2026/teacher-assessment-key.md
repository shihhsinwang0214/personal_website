# 前瞻資訊科技教師版答案與評分

本檔含作業與短測驗答案，與[學生版](./student-assignments-and-quizzes.md)分開發放。兩次測驗各 30 分，作業各 10 分，均為本單元原始分數；如何併入整門課的成績由授課者決定。

## 測驗進行方式

16:40–17:10 個人作答。可允許一張自己的 A4 筆記，保留低壓、重理解的性質；使用規則應於考前統一公告。建議學生以八分鐘完成單選、十六分鐘完成短答、六分鐘檢查。17:10 收卷後，用最後十分鐘講評兩三個主要誤解。

短答不要求出現英文術語，只要任務、改動對象與理由正確就給分。不要把沒背出論文名、沒寫出完整群作用式或沒記得 benchmark 數值當成扣分項。

## 作業 A 評分與示例

| 項目 | 分數 | 給分依據 |
| --- | ---: | --- |
| 輸入與輸出 | 2 | 各寫清楚一項，不只寫「做 AI」 |
| 兩種變化與答案規則 | 3 | 第一種正確 1 分，第二種正確 1 分，能交代原因或條件再 1 分 |
| 表示或模型的理由 | 3 | 選擇合理 1 分，說出使用的關係 1 分，連到自己的任務 1 分 |
| 限制 | 2 | 描述具體失效或不足情況，且不把一致性當成正確率保證 |
| 合計 | 10 | 不按圖片精美、工具費用或程式能力評分 |

**可接受示例：** 輸入是完整杯子點雲，輸出是杯子的物件類別。重新排列資料列與整體旋轉都不改變類別，假設任務不把方向當成類別。選 PointNet 處理集合順序，另指出基本 PointNet 的排列性質不自動保證任意旋轉不變，還需要相應設計或資料策略。若任務改成預測杯口朝向，旋轉時方向答案就應一起轉。

也接受影像／CNN、路網／GNN 或其他合理選擇。只要說清楚額外假設，就不因學生選了不同架構扣分。若聲稱「CNN 保證所有角度都相同」「attention 一定理解語意」「PointNet 自動具備所有 3D 對稱」，應在相關項目扣分並指出缺少的條件。

## 作業 B 答案與評分

權重總和為 15。最高分法永遠選 D；按權重抽樣時：A 為 1/15，B 為 4/15，C 為 2/15，D 為 8/15。

重複使用這份固定表時，最高分法只回傳 D；權重法可能回傳全部四種，D 最常見。權重法也可能回傳 A、C 這類不滿足完整要求的結果。B、D 提供兩種符合要求的構圖；是否符合要求與 reward 的數值需要一起檢查。

兩種選擇都沒有更新模型 θ。如果四個候選已經生成完，最後的挑選不會省掉那些已花掉的生成計算。這是在同一有限候選集上的選擇；和從整個圖片空間精確抽到某個 tilted target 是不同問題。

| 項目 | 分數 | 給分依據 |
| --- | ---: | --- |
| 最高分選擇與權重機率 | 4 | D 正確 1 分；總權重 15 與四個比例正確共 3 分，可按比例酌給部分分數 |
| 重複選擇的差異 | 2 | 最高分法固定 D、權重法可能多種且含不合格候選，各 1 分 |
| 額外評估 | 2 | 合理性／要求符合度、有效候選內的多樣性、成本等兩項，各 1 分 |
| 模型與成本 | 2 | θ 不變 1 分；未省去已完成的四次生成 1 分 |
| 合計 | 10 | 不要求真的抽樣，沒有觀察到的隨機頻率不扣分 |

## A9 地圖的三種輸出

**參考答案：** 判斷是不是臺大的 label 保持相同。總圖的螢幕位置一起旋轉再平移。方向箭頭跟著旋轉，整張地圖的平移不改變這支向量。

位置描述在座標系中的點；方向箭頭描述兩點之差，兩端共同平移時平移量抵消。符合變換規則不保證答對，例如永遠輸出同一個錯誤分類，可能仍然滿足旋轉不變。

| 給分點 | 分數 |
| --- | ---: |
| label 不變 | 1 |
| 位置同時旋轉與平移 | 1 |
| 向量只跟著旋轉 | 1 |
| 分清點的位置與方向向量，並說明共同平移抵消 | 2 |
| 指出一致性不等於準確，並給出合理理由或反例 | 2 |
| 合計 | 7 |

只寫「equivariant」但未說明位置和向量如何變，不能拿滿表格與解釋分。學生用圖畫對也可給分。

## A10 選一個計算用 graph

**參考答案：** Q 不連通，兩個三角形間沒有沿邊傳遞的路徑。在只要求連通與少邊的題目設定下，R 有 5 條邊且連通，比 P 的 15 條邊少，所以選 R。

R 是鏈狀 graph，只知道相鄰邊長時可轉動關節而改變形狀，因此連通與 sparse 不足以保證幾何唯一性。預測效果還取決於節點／邊特徵、任務、網路與訓練。R 的較長路徑也可能需要較多 message-passing 輪次；題目沒有把這項成本排進選擇要求。

| 給分點 | 分數 |
| --- | ---: |
| Q 不連通 | 1 |
| 兩組之間無訊息路徑 | 1 |
| 選 R 並引用連通 | 1 |
| 引用 5 條邊少於 15 條 | 1 |
| 明確否定從連通／少邊推出唯一形狀或最佳正確率 | 1 |
| 提出關節可動、缺少幾何限制、特徵／任務／訓練等具體理由 | 2 |
| 合計 | 7 |

若學生更完整討論實際運算，指出 P 在固定少輪數下可能有其他優點，但仍正確回答本題的兩個指定要求，應照給分，不因提出合理取捨扣分。

## B9 判斷改了哪一個部分

| 操作 | 更新 θ | 分類 |
| --- | --- | --- |
| 換 prompt，沿用原 sampler | 否 | 使用既有條件模型 |
| 偏好資料加梯度下降更新模型 | 是 | Fine-tuning |
| 八張候選用 reward 挑一張 | 否 | Test-time steering，具體為 Best-of-N |

每列 θ 是否更新 1 分、分類 1 分，共 6 分。最後 1 分：不能只看有沒有梯度；要看對誰微分、實際更新哪個量。對樣本求梯度且保留 θ，可以屬於 test-time guidance。

若學生指出換 prompt 在廣義語用上也能稱控制生成，接受這個補充；仍應分清題目刻意比較的「沿用已學條件輸入」與「額外改 sampling／搜尋」。不要要求學生聲稱二者在所有文獻裡都有互斥的命名。

## B10 評估 steering 的取捨

**參考答案：** P 的平均 reward 0.90 最高，但多樣性只有 0.10，所以不能只據此宣稱整體最好。在成本同為 800，且希望保留高分結果多樣性的要求下，可以選 Q：reward 為 0.85、接近 P，diversity 為 0.60、明顯高於 P。

表格僅有假設設定下的幾個平均指標。若要比較一般效能，還需更多任務、樣本數、變異或重複實驗；若要判斷 target sampling，還需明確 target、分布比較或相應理論與條件。高 reward 或高 diversity 本身都不能證明精確 target sampling。

| 給分點 | 分數 |
| --- | ---: |
| 指出 P 的 reward 最高 | 1 |
| 指出單一指標不足，引用多樣性或成本取捨 | 1 |
| 依指定偏好選 Q，引用至少兩個相關數值 | 2 |
| 明確指出表格不能支持跨所有任務或精確 target 的主張 | 1 |
| 提出一項相應且具體的額外證據 | 2 |
| 合計 | 7 |

若學生在第一小題寫「對只追 reward 且預算允許的人，P 可能合適」，這是合理的條件式判斷；不要因選擇不同偏好扣分。第二小題仍須回應題目指定的多樣性需求。
