2. `02-posterior-mean.png` — squared-error denoiser returns a posterior mean, not one candidate.
3. `03-tweedie-score.png` — posterior mean correction and the noisy marginal score direction.
4. `04-schedule.png` — fixed endpoints, different coefficient schedules.
5. `05-coupling.png` — fixed marginals, different couplings.
6. `06-gamma-path-thickness.png` — deterministic path versus a path with Gaussian thickness.
7. `07-exact-ctmc-vs-tau-leaping.png` — sequential exact jumps versus parallel approximate updates.
8. `08-tau-leap-step.png` — the three operations in one tau-leap.
9. `09-tau-leaping-errors.png` — finite-step error, factorization error and remasking cost.
